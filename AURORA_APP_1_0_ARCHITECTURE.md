# AURORA — App Architecture 1.0

## Product model
AURORA is session-centric, not content-centric.

Primary loop:
AVANT → PENDANT → APRÈS → REFAIRE

Primary navigation:
AUJOURD'HUI · TERRAIN · LAB · MES PHOTOS · EXPLORER

The corpus is a knowledge layer behind the experience. Q01–Q12 are contextual cognitive prompts, not a chapter list.

## Session
A session stores locally:
- intention
- situation
- decision / constraint
- shot count
- observations
- critique
- completed exercises

## Design principles
1. One primary decision per screen.
2. Progressive disclosure.
3. Direct manipulation before prose.
4. Bottom navigation for top-level areas.
5. Sheets for secondary content.
6. Material is an implementation layer, not the method.
7. Offline-first.
8. User photos stay local in this prototype.

## Source preservation
The embedded DATA object is inherited from the stable Aurora XI corpus-backed prototype and preserves:
Q01–Q12, intentions, situations/cards, book index, exercises, device layer, principles and research references.

# AURORA XII

Prototype mobile-first d'AURORA, reconçu comme un outil de décision photographique.

## Déploiement GitHub Pages

Copier tout le contenu de ce dossier à la racine du dépôt GitHub Pages, avec `index.html` à la racine.

## Principes UX

- 3 portes principales : Photographier / Terrain / Diagnostiquer
- navigation mobile persistante pour les tâches fréquentes
- bibliothèque comme mémoire du système
- laboratoire comme espace d'expérimentation
- progressive disclosure
- interactions tactiles >= 48 px quand possible
- support de `prefers-reduced-motion`
- contenu et relations conservés dans les données AURORA
